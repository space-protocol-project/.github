# [Space Protocol](https://space-protocol-project.github.io/space-protocol)

Открытый проект self-hosted социальных пространств: каналы, чат, форум, лента, голосовые комнаты, конференции и эфиры в универсальном клиенте.

Владельцы размещают серверы самостоятельно и управляют ими через встроенную веб-панель. Идентичность принадлежит пользователю; устройства, восстановление и права доступа проектируются явно.

Проект находится на этапе архитектуры. Основное направление API — Protobuf, gRPC и grpc-gateway; медиатранспорт — WebRTC/HLS. Протокольная основа сравнивается с Matrix, XMPP и Nostr до окончательной фиксации.

Первая цель — текстовый сервер, два клиента, надёжная синхронизация, recovery и отзыв устройства. Production release и открытая лицензия пока не объявлены.
